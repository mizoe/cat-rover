# ESP32-S3 GPIO割当表（cat-rover）

- 対象ハード: Freenove Media Kit for ESP32-S3（FNK0102）3.5インチ版
  - ESP32-S3-WROOM-1（Octal PSRAM 8MB）＋ 3.5" TFT（ST7796/ST7365, SPI 320x480）
- 方針: **案C** — メディアボード装着のまま車載。マイク（猫の声を拾う用途で将来使用）は維持し、**SDカードを廃止してCAN（TWAI）に転用**
- ESP32の役割: カメラ配信 / Wi-Fiゲートウェイ / 車載ステータス表示 / 音声入出力。車両制御はSTM32側（CAN経由）
- 出典: Freenove公式 FNK0102 Preface（Notes for GPIO）

## 廃止する機能

- SDカード（GPIO38/39/40）: SD_MMCを初期化しない。**運用中はSDカードを挿さない**（挿すとバスが衝突する）。
  - 効果音 → 内蔵Flash（LittleFS）に格納
  - 猫の声の録音・ログ → Wi-Fi経由でPCへ送信

## CAN（TWAI）接続

- トランシーバ: 3.3V系（例: SN65HVD230）
- ESP32 GPIO38 → トランシーバ TXD、GPIO39 ← トランシーバ RXD
- ビットレート: 500 kbps（仮。STM32側と合わせて確定）
- 終端: バス両端に120Ω
